#Nama Aplikasi:
Perpustakaan.

#Tujuan:
Membuat web app perpustakaan menggunakan PHP dan Laravel.

#Cara menjalankan project secara lokal:
1. Jalankan php artisan serve untuk menjalankan development server
2. buka htttp://127.0.0.1:8000 di browser untuk melihat view dari program.

#Perbedaan model, view, dan controller.
Model adalah pengelola logika data dan interaksi langsung dengan database. View berfungsi sebagai antarmuka visual yang menampilkan data dan informasi kepada user. Sementara itu, Controller bekerja sebagai jembatan yang menerima permintaan pengguna, memproses logika aplikasi melalui Model, lalu mengembalikan hasilnya ke View.
